The API is unchanged. To migrate, replace the old package with the new one:
  
  ```shell
  npm uninstall @neolution-ch/react-formik-ui
  npm install @collana-solutions/react-formik-ui
  ```
  
  Then change the imports from `@neolution-ch/react-formik-ui` to `@collana-solutions/react-formik-ui`.
  
  `@neolution-ch/react-formik-ui` gets deprecated and receives no further releases.
